## Dynamic data -> DB (`missions` table, ordered by `position`)
| UI | column |
|---|---|
| `NN` prefix | `position` (1-based, zero-padded to 2) |
| title text after dot (`QR ვიზიტი`) | `titleKa` (+ `titleEn` NOT NULL) |
| icon | derived from `type`: `visit_qr` -> qr icon, `upload` -> camera icon, `social_post`/`invite` -> no icon in design (pick) ; `check` icon used for 03 (generic) |
| `აუცილებელი` / `დამატებითი` | `required` true/false |
| `100 XP` | `xpReward` |
| `კრეატიული ვიდეო · 15–30 წამი` | free summary built from `type` label + `config` `{minSeconds:15,maxSeconds:30,mediaType:"video"}` |
Unlock order: no UI control in these screens for `unlockAfterMissionId` (video unlocks after QR) -> implied by order; flag. Mission `levelId`, `placeName/lat/lng` (visit_qr location!) have no UI in the design -> flag (a visit_qr mission needs a place).
Subtitle for row 1 is `required · xp`, for row 2 is `type label · duration` (inconsistent pattern in design; row 2 does not show XP/required).
