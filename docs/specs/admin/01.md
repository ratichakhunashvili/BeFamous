## Behaviour / data
- Submit `შესვლა`: POST email+password to the same auth endpoint as users; server checks `role === "admin"`; success → admin dashboard (`/admin`); non-admin or bad credentials → generic error (no error state is designed; propose inline error under password field or banner, copy not in Figma).
- Dynamic: none besides form values. No validation messages in design (propose: required + email format).
- Interactive map: logo (not clickable in design), `მომხმარებლის სივრცე` → user site, theme switch → toggle theme, `პაროლის აღდგენა` → 25, `რეგისტრაცია` → 02 (drop for admin).
