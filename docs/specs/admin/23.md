## Field -> DB (flag: no settings table)
- ბიზნესის დასახელება: **no column** (it also feeds the header breadcrumb `ქარხანა Coffee`). For BeFamous admin map to a platform setting (new `site_settings` key/value or env), or drop; the breadcrumb should become e.g. `BEFAMOUS / ადმინი`.
- საკონტაქტო ელფოსტა: **no column** (not `users.email`, which is the login identity). Same new settings store.
- Alternative real mapping: show the admin's own profile (`users.name`, `users.email`, `users.locale`) — a re-purpose, not in design.
Validation (proposed): name 1-80; email valid format. Save -> 47.
