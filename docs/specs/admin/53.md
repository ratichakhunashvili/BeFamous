## Intended function (derived from copy + schema)
"Check owner, validity date and usage status." Build as: code input -> lookup `vouchers.code` (exact, trim, normalise en/ASCII dashes) -> result card showing
- owner `users.name`/`email` via `vouchers.userId`
- reward title via `rewardId` (`rewards.titleKa`, `valueGel`, `brand`)
- `status` (issued / redeemed / expired; treat `expiresAt < now` as expired even if status still issued)
- `expiresAt`, `redeemedAt`
- action "mark as redeemed" -> set `status='redeemed'`, `redeemedAt=now()` only if issued and not expired; write `auditLog` (`action:'voucher_redeem'`, `target: voucher id`, `actorId`). **These controls (input, button, results) are NOT in the design — proposal.**
Code format: schema `vouchers.code` unique; project format `BF–50–XXXX` with **en dashes**; the Figma sample `BF-LUM-7Q2K` uses ASCII hyphens and a different segment (LUM) — flag mismatch.
