## CSV columns (to generate)
Shown columns, exact headers (Georgian) / suggested keys: `მეტრიკა` (metric label) | `რაოდენობა` (value, plain integer without thousands separator in the file; "1,284" is display formatting) | `პერიოდი` (period label, e.g. `ნოემბერი`).
Proposed (not in design, flag as proposal): add `period_start`, `period_end` (ISO dates, Asia/Tbilisi), `source`, `generated_at` columns, and a campaign column, so the file is self-describing and obeys "source + timestamp". Use UTF-8 with BOM so Excel renders Georgian.
Rows in design: views, participants, QR visits only. Candidates to add (all have sources): approved submissions (`ნამუშევრები მიღებული`), vouchers issued/redeemed.
Rule: when a metric is unavailable (views with no `social_posts.metrics`), write an EMPTY value cell (or the text `მიუწვდომელია`), never `0`.

## Data mapping
Rows reuse the same queries as `20.md` (views = SUM social_posts.metrics.views over posts with non-null metrics; participants = COUNT DISTINCT participations.user_id by joined_at; QR = COUNT checkins joined qr_codes->missions by challenge). Period label = month name of range (`ნოემბერი`) in the mock; for 7d/30d use the actual range text. No metric here lacks a source except views, which depends on manual admin entry.
