## Field -> DB (`rewards`)
| Field | Column | Validation (proposed; design shows none) |
|---|---|---|
| დასახელება | `titleKa` (required). **`titleEn` NOT NULL has no field in the design** -> add EN title input or default/copy | non-empty, <=120 |
| რაოდენობა | `stock` (nullable integer) | integer >= 0 (blank = unlimited) |
| ვადა | `expiresAt` | valid date, in the future |
Not in design but in schema: `descriptionKa/En`, `brand`, `valueGel`, `usageKa/En`, `xpCost`, `challengeId`, `active`. Design hint "შეავსე ვაუჩერის სახელი, ღირებულება და ვადა" mentions **ღირებულება (value)** but no value field exists in the form -> `valueGel` field is missing in design (flag). Recommend adding optional fields below the three or an "advanced" section; keep the three as shown.
