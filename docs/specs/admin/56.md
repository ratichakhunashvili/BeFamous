## Events shown and proposed derived queries (no admin-notifications table exists; `notifications` is per-user)
| Event | Derived from |
|---|---|
| New submission to review (row 1) | `submissions where status='pending'` join `users` (name), newest first; text `ახალი ნამუშევარი — {user.name}-მა ვიდეო გამოგზავნა` (design says "ვიდეო" though submissions are post links — use "ნამუშევარი/პოსტი") |
| Campaign ending soon (row 2) | `challenges where status='active' and endsAt between now() and now()+7d`; shows `titleKa · {D month}` of `endsAt` |
| Invite sent / team (row 3) | no equivalent: team invites do not exist (see 54). Replace with e.g. new `socialPosts` needing review (`status in ('found','ownership_check')`) or expired vouchers soon (`vouchers` issued with `expiresAt` within 7d). |
Optionally also: submissions `revision` resubmitted, `socialPosts.status='refresh_failed'/'auth_expired'`. Read/unread state needs new storage (e.g. `admin_notification_reads(userId, key, readAt)`); otherwise purely derived, count = badge. Destinations (propose): submission -> review screen for that submission; campaign -> campaign edit. Button destination unspecified (likely dashboard) — flag.
