## Data mapping (`rewards`, `vouchers`)
| Column | Source |
|---|---|
| ჯილდო | `rewards.titleKa` (locale ka; `titleEn` for en). Design shows the value baked into the title ("50 ₾ ყავის ვაუჩერი"); `valueGel` could generate "50 ₾" prefix but titles are free text. |
| რაოდენობა | `rewards.stock` (null = unlimited -> show `∞`/`—`, not designed) |
| გამოყენებულია | `count(vouchers where reward_id = rewards.id and status='redeemed')` (alt: issued total; label says "used", so redeemed) |
| ვადა | `rewards.expiresAt`, formatted `D` + Georgian month abbreviation = first 3 letters of month (`ნოე`=ნოემბერი, `დეკ`=დეკემბერი); null -> `—` |

Query: `select rewards.*, count(*) filter (where v.status='redeemed') as used from rewards left join vouchers v ... group by rewards.id order by created_at desc`. Should inactive/expired rewards show? Design silent; propose show all with muted dimming for `active=false` (proposal).

Admin guard: `users.role = 'admin'` required for all `/admin/*`.
