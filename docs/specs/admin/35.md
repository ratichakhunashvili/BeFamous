# 35 · მისიის რედაქტირება (mission edit)

- Figma frame `22:830` (visible layer `88:12712`). Screenshot `docs/specs/admin/img/35.png`.
- Route: `/admin/campaigns/[id]/edit/missions/[missionId]` (and `/new` for creating).
- Shell, tokens, field styling: see `12.md`. Header back -> 13, `+ ახალი კამპანია` -> 06. No stepper on this screen.

## Layout
- Caption: `კონსტრუქტორი  /  მისია`
- H1: `მისიის რედაქტირება`
- Body muted: `მიუთითე რა უნდა გააკეთოს მონაწილემ და როგორ შეამოწმებ.`
- Form panel 768 (surface, 1px border, radius 16, padding 24, gap 16), titled H3 18/27 Bold `მისიის დეტალები`, then 4 fields (720 wide, same input style as 12) and the button row.

## Fields
| label | control | sample | DB column |
|---|---|---|---|
| მისიის სახელი | text input | `კრეატიული ვიდეო` | `missions.titleKa` (+`titleEn` NOT NULL; EN field missing in design) |
| დავალების ტიპი | select | `ვიდეოს ატვირთვა · MP4 / MOV` | `missions.type` enum: `visit_qr`, `upload`, `social_post`, `invite`. Sample = `upload`. Only one option's label is shown; labels for the others are not designed (propose: QR ვიზიტი / ვიდეოს ატვირთვა / სოციალური პოსტი / მეგობრის მოწვევა). |
| შემოწმების კრიტერიუმი | text input | `ვერტიკალური ვიდეო, 15–30 წამი` | `missions.descriptionKa/En` and/or `missions.config` `{minSeconds:15,maxSeconds:30,mediaType:"video"}` |
| XP და მოთხოვნა | combined input | `150 XP · აუცილებელი` | `missions.xpReward` = 150 AND `missions.required` = true (two columns in one control; design to be split into number input + required toggle) |
No control for: `position`, `unlockAfterMissionId`, `levelId`, `placeName`/`lat`/`lng` (visit_qr), `descriptionEn`. Flag.

CONFLICT with confirmed product decision (memory): no video uploads/storage - posts live on TikTok/Instagram. `ვიდეოს ატვირთვა · MP4 / MOV` (file upload) contradicts it; implement type `upload`/`social_post` as "submit a link to the TikTok/Instagram post" and relabel; flag for owner.
