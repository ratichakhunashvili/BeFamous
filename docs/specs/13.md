## What the user does here (IMPORTANT)
NOT a device file upload. Despite the frame name, there is NO drop zone, no file picker, no "accepted formats / max size" text. The user has already published a video on TikTok/Instagram and now **registers the POST**: either (a) link a social account and pick a post from it (→56), or (b) paste a post URL. So: social POST LINK / account-picked post only. Both paths exist on the same screen.
Inputs: exactly ONE text field (post URL, placeholder `მაგ. https://www.tiktok.com/@…`). Plus one link-row control (connect account).
- `ანგარიშის დაკავშირება` row (Figma name "Control · ვიდეოს დამატება ⇢56") → 56 (link TikTok/Instagram account, then 57 pick a post). This is what the prototype calls "ვიდეოს დამატება".
- URL field (Figma name "Control · ვიდეოს ბმული → mediaReady") → 41. In Figma the whole field is a link to 41 (drawn as a non-editable placeholder). Implement as a real `<input type=url>` with a trailing play icon button; submitting a valid TikTok/Instagram URL (Enter or tapping the play icon) → 41. Prototype map: `ვიდეოს ბმული→41`.
