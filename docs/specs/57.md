## Selecting a post
Tapping row A -> 41 (post registered / submitted-for-review), row B -> 15 (hashtag-missing outcome), row C is disabled. The row's status text is derived: eligible = has required hashtags AND published within campaign window; else show reason. Suggested data: social_posts with title, published_at, hashtags[], eligibility.
